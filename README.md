# ITOF 2026 Navigator

Mobiler Navigator für die ITOF 2026 (22.–23.9.2026, Flughafen Dresden): Programm filtern, eigenen Ablauf zusammenstellen, Räume und Stände auf den Standplänen finden, ÖPNV-Verbindungen zur Veranstaltung und zurück abfragen.

- `index.html` – der Navigator (Programmdaten und Standpläne eingebettet)
- `itof26-programm.json` – Programmdaten; wird bei Auslieferung über GitHub Pages bevorzugt geladen

Quelle: Programm, Stand 21.9.2026, und Standpläne Ebene 1–3. Zeiten mit „ca.“ sind im Programm nicht beschriftet und aus der Rasterposition geschätzt.
ÖPNV-Daten: öffentliche, inoffiziell dokumentierte WebAPI des VVO (webapi.vvo-online.de), ohne Gewähr; benötigt Internetverbindung.
Privat erstellter Navigator – kein offizielles Angebot des Veranstalters oder des Freistaates Sachsen.
Auswahl, Pausen und Starthaltestelle werden nur lokal im Browser gespeichert (localStorage).
