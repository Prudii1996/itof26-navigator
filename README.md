# ITOF 2026 – Veranstaltungs-Guide

Mobiler Guide für die ITOF 2026 (22.–23.9.2026): Programm filtern, eigenen Ablauf zusammenstellen, Räume und Stände auf den Standplänen finden.

- `index.html` – der Guide (Daten und Standpläne eingebettet, läuft auch offline)
- `itof26-programm.json` – Programmdaten; wird bei Auslieferung über GitHub Pages bevorzugt geladen

Quelle: Programm, Stand 21.9.2026, und Standpläne Ebene 1–3. Zeiten mit „ca.“ sind im Programm nicht beschriftet und aus der Rasterposition geschätzt.
Privat erstellter Guide – kein offizielles Angebot des Veranstalters oder des Freistaates Sachsen.
Die Auswahl wird nur lokal im Browser gespeichert (localStorage).
